# Writing guide

Every agent that drafts or edits a post follows this file. Edit section 1 to match your voice. Agents append to section 3 as they learn from your edits.

## 1. Voice
- First person. Practical over hype: every post answers "so what should the reader do or know?"
- Concrete beats abstract: numbers, named tools, real examples, costs, time.
- Short paragraphs, plain words, no filler. No emojis.

## 2. Post requirements
- Title ≤ 60 characters, main keyword near the start. Description 120–160 characters.
- Slug: short ASCII kebab-case in the post's language.
- No H1 in the body. Use `##` sections. Answer the question in the first 2–3 sentences.
- Every post targets one keyword from `seo/keywords.md`, stored in `keyword`.
- Link primary sources. Never invent facts, quotes, numbers or links.
